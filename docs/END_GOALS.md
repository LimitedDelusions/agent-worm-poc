# End Goals and Decision Gates

## Successful POC

The POC is successful when:

- all four models complete benign tasks;
- the positive control proves assay sensitivity for every ordered pair;
- sham scoring has no false positive;
- hardened processing remains below its propagation ceiling;
- neutral shakedown shows within-block ordered-pair variation;
- the full matrix completes with acceptable invalid-output and utility rates;
- evidence and provenance verify successfully.

A successful POC means the question is measurable. It does not require a statistically significant pair effect.

## Advance

Advance to the formal proposal when controls are valid and the main evidence shows enough variance to estimate a final-study sample size. Bring the generated meeting summary, transmission matrix, controls, limitations, and actual cost to the instructor.

## Revise

Revise before advancing when the neutral workflow is universally zero or universally successful, semantic mutation dominates exact scoring, or one model cannot perform the task reliably.

## Stop or change the question

Change the primary variable when controls work but ordered model assignment produces negligible variation across the full POC. A valid null result is still useful and must not be tuned away post hoc.
