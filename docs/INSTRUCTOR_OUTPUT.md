# Instructor Output Template

The gated run should support a one-page summary containing:

- exact research question;
- exact models and revisions;
- workflow diagram;
- compatibility result;
- positive-control rate and pair matrix;
- neutral two-hop rate by placement;
- intake→relay conditional transition matrix;
- hardened comparison;
- benign utility and invalid-output rate;
- placement permutation statistic and matched-policy result;
- semantic-review status;
- observed compute cost;
- decision: advance, revise, or abandon placement as the primary variable.

Do not claim that a POC “proved” the hypothesis. State whether it demonstrated a feasible, measurable, reproducible signal suitable for the formal research proposal.
